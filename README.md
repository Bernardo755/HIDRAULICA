# HidroPro v4 corregida

Esta versión mantiene una carpeta `data/` funcional y separa datos técnicos de la lógica.

## Estructura
- `index.html`: entrada única.
- `css/`: estilos.
- `js/`: aplicación y motor de cálculos.
- `data/`: fluidos, tuberías, accesorios, aparatos, materiales, criterios y fórmulas.

## Importante
Sube **todo el contenido** conservando las carpetas. `data/` NO debe quedar vacía.

La app no usa frameworks ni CDN, por lo que funciona en GitHub Pages sin dependencias externas.
